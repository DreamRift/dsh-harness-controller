## 二、样式沉淀（消除逐处硬编码）
- 新增 `DshTheme.xaml`：**BtnInline**（BasedOn BtnSecondary，Padding 13,8 / MinWidth 0 / MinHeight 34）——行内动作钮统一规格。
- 收编：PluginManagePanel 升级/卸载 2 处 `Padding="13,8"`、UsageView 刷新 1 处 → 全部改 `Style="{StaticResource BtnInline}"`；全工程 `Padding="13,8"` 残留 **0**。
- 尺寸/排布类改动：缩字后无一处仍需动列宽（见下走查），故本类未改任何布局结构（保守边界，避免连带回归）。
