## 3. 交互流程

1. 进页：读档案 → 立即渲染上次结果（不等采集），LastGoodAt 显示新鲜度；档案陈旧感由 ↻ 手动解决（铁律：无定时拉采）。
2. 范围切换（实例 × 时间 两级）：纯内存 Summarize 重算，无加载态；已删实例档案保留可查（现状能力保留）。
3. 按天钻取：点柱 → 选中态（柱主色+「清除」）→ 下方展开「当日条」（当日四桶+当日模型构成），会话明细过滤为该天；再点同柱/清除回总览。
4. 统一视图下钻：点实例卡 → 切入该实例聚焦视图（下拉选中同步）——实例对比=横向看卡，实例细节=进聚焦。
5. 会话行：点击行 → 行内展开四桶精确值 + CWD + 会话 ID（ID 带复制钮）。
6. 刷新（重态明示，调研 §3.2）：↻ 按下 → 变进度环且按钮禁用 → 逐实例强制重采（现有 RefreshCommand 语义不变）→ 完成显示摘要「采集完成：成功 X · 失败 Y（实例名）」，失败实例同时进入页顶黄条；
   ModelsComplete=false 时按模型/按天提示条常驻。**不加“中途取消”**（单飞短任务、取消收益<交互复杂度——已定决策，供评审推翻）。
   刷新期间范围切换仍读旧档不阻塞。
8. hover 密度分级（调研 §3.3）：模型行/按天柱/实例卡数字悬停 → tooltip 精确值+口径（DSH 紧凑数形 517/12.2K/517K 沿用现状 FormatTokens）；点击会话行展开区给原始 N0 值。
7. 空态两分：无档案（给采集钮）/范围内无记录（给换范围钮），文案直给可行动。

## 5. 实施落点承诺（通过评审后动码）

- **Core/Usage/UsageQuery.cs**：新增纯静态函数（均配 xUnit）：①逐日归并（跨模型 Daily → 单实例序列，供迷你趋势）；②当日×模型构成（Day 的模型占比表）。无 IO、无新采集。
- **ViewModels**：UsageViewModel 增选中日钻取状态、统一视图实例卡集合（名称/retired/运行徽标/无数据态/单源 Summarize）；UsageRows 增实例卡行模型、UsageSessionRow 暴露 SessionId（复制钮）。
- **App**：UsageView.xaml 按线框重排（code-behind 仍只注入+生命周期转发）；IArchiveFacade/ArchiveHub 加 liveness 透出只读方法（仍是档案读，不新采集）。
- **不变量**：档案四不变量、分面 TTL、RefreshCommand 语义不动；门禁+单测+GUI 冒烟照常。
