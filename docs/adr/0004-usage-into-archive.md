# ADR 0004：token 用量并入档案，而不是保留独立备份文件

- 日期：2026-09-01 ｜ 状态：已采纳

## 背景
用量原型把快照写在 exe 旁的 `usage-backup.json`（全量重写、含已删除实例的历史），
与新的档案体系是两套并行的持久化。

## 结论
用量成为档案的 `usage` 分面；原型备份经 `--import-usage` 一次性导入（幂等，已有更新数据的实例跳过），
清单里已不存在的实例照样建档并标记退役。

## 后果
- 只有一套持久化与一套"失败不覆盖"语义。
- 跨重启的逐文件增量游标未做：档案已保存最终聚合结果、TTL 内不重扫，收益有限而会显著增大档案体积。
