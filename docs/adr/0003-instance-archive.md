# ADR 0003：实例档案作为界面唯一数据源

- 日期：2026-09-01 ｜ 状态：已采纳

## 背景
版本探测只有进程内内存缓存（无 TTL、无持久化），已装插件完全无缓存每次重扫，netstat 3s 缓存，
插件目录 24h 磁盘缓存——四套策略各写各的；用户诉求是"不同信息不同刷新间隔，并形成不随实例删除而消失的档案"。

## 结论
每实例一份 JSON 档案，按"分面（facet）"组织，每个分面自带 `collectedAt/lastGoodAt/status/error` 与独立 TTL。
四条不变量：单飞、失败不覆盖成功数据、删除只标记退役、落盘去抖。界面只读档案。

## 后果
- 冷启动即有数据；WSL 这类昂贵采集不再每次进页面都做。
- 档案会随会话增长，用量分面因此限制会话明细上限（500 条）并按天聚合。
- 新增信息类型的成本固定为"采集器 + DTO + TTL + 测试 + Gallery 状态"。
