# ADR 0002：运行时状态迁到用户级目录，保留便携模式

- 日期：2026-09-01 ｜ 状态：已采纳

## 背景
`instances.json` 写在 exe 旁，于是每个构建产物、每份拷贝各有一套实例清单（本机实测存在 5 份互不相通的副本），
"换个目录运行实例就全没了"。

## 结论
状态统一落 `%LOCALAPPDATA%\DshController\`（由 `AppPaths` 单源提供）；exe 旁存在 `portable.marker` 时回到便携模式；
首次运行自动从 exe 旁**复制**导入（不删除源文件）。额外保护：若目标是空清单而源非空，备份目标后接管——
避免"先跑了一次全新产物、再部署到旧目录"把清单永远导不进来。

## 后果
- 升级路径需要用户知道：新版本首次启动会导入旧清单，旧文件留作回退。
- 便携用户需自己放 marker 文件（README 已说明）。
