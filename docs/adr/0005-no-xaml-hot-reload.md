# ADR 0005：不承诺 XAML 热重载，改用设计台

- 日期：2026-09-01 ｜ 状态：已采纳

## 背景
用户希望"换一个便于管理、改进以及修改界面的流程"。核实结论：WinUI 3 的 XAML Hot Reload 依赖 Visual Studio，
`dotnet watch` 不支持 XAML 热更新。

## 选项
1. 承诺热重载——做不到。
2. 运行时用 `XamlReader` 重解析资源字典——只支持 XAML 子集，风险高、收益不确定。
3. 设计台（本决策）：所有令牌、控件样式、状态分支用假数据摆在一页，配合 15 秒 Debug 构建。

## 结论
选 3；选项 2 留作可选 spike，失败即弃，不进主线。

## 后果
改样式的回路是"改 XAML → 15s 构建 → 看设计台一页"，不必制造真实运行条件（失败态、空态、WSL 未运行…）。
