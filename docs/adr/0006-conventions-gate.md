# ADR 0006：把"不留屎山"变成构建门禁

- 日期：2026-09-01 ｜ 状态：已采纳

## 背景
用户的硬要求是"最重要的是不许留有屎山"。口头约定会随时间失效，必须机器可检。

## 结论
`tools/check-conventions.ps1` 在每次构建前运行，违规即失败：
文件 ≤400 行、Core 禁 UI 引用、裸 catch 必须写"理由:"或日志、async void 限事件处理器、App 层禁同步阻塞。
历史欠账登记在 `tools/conventions-allow.txt`，**只减不增**，随阶段清零。

## 后果
- P3 结束时 InstancePanel 的 R1/R3 例外已全部删除，当前扫描 90 个文件 0 违规。
- 新代码想加例外必须写理由并被评审看到——成本高于把代码写对。
